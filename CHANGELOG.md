# Changelog

All notable changes to Classroom+ are documented here.

## [0.1.0] - 2026-09-17

### Added
- Initialized the Classroom+ React + TypeScript project with Vite.
- Established the initial project directory structure.
- Added component, page, layout, hook, data, library, style, and type directories.
- Added extension, documentation, and asset directories.
- Added initial TypeScript type definitions for assignments and classes.
- Added placeholder files for the initial application architecture.

### Notes
- This release establishes the project foundation only.
- Google Classroom API integration is not included yet.
- Mock data and the initial UI are planned for v0.1.1.
